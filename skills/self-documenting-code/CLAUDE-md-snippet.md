# CLAUDE.md 用スニペット（任意）

スキルの発火に頼らず常時効かせたい場合、以下を CLAUDE.md に貼る。
コストは常時この数行のみで、詳細はスキル発火時に補完される。

```markdown
## コメント・ドキュメント規約

- 依頼・差分・会話を実況するコメントを書かない（「〇〇対応のため追加」等）。
  変更の文脈はコミットメッセージに書く。コメントはコードの現在の姿を書く。
- 意味情報を足さずに隣接コードや識別子を言い換えるコメント・doc を書かない。
- .ts/.tsx では JSDoc に型を書かない（@param {Type} 禁止）。@param は
  名前＋型を超える意味（単位・役割・省略時の挙動）がある引数だけに書く。
- 関数の doc には契約を書く。偶発的な呼び出し元（「〇〇画面で使う」）を書かない。
- 自分の変更で嘘になった近傍のコメントの更新・削除は変更の一部。
  リファクタリングで有用な既存コメントを剥がさない。
- コメントの言語・密度はファイルの慣習に合わせる。
```
